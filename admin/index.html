Sign in

The instructor password signs every command, and each kiosk refuses anything it can't verify. The password never leaves this page. The GitHub side is handled by the club's API (brophy-uav-api.netlify.app), which holds the repo token so this page doesn't have to.

Kiosks Approvals

Approve a badge

For bench and witnessed badges. The pilot has DM'd their photo (or you watched them do it); you approve here and a signed badge.award command goes to the selected kiosk, which records it and syncs it to the other one. Quiz badges are earned at the kiosk by passing the quiz — only use this to override. Nothing here can be undone by a student; Revoke is yours alone.

Approving a badge that is already earned is harmless.
